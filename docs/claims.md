# Claims ledger

This document is the authoritative claims ledger for `@lit-core`. Every numerical metric, benchmark performance figure, and architectural capability claim made across the repository, whitepapers, and documentation maps directly to an exact reproducible command and test suite.

## Verification methodology

Claims are categorized into three verified statuses:
1. **Verified**: The claim is backed by automated tests or benchmarks running in CI and reproducible locally.
2. **Pending remediation**: The claim is an architectural target undergoing remediation (milestones M0 through M8).
3. **Retracted**: The claim was previously asserted without genuine measurement and has been formally withdrawn.

## Maintenance and audit protocol

1. **Continuous synchronization**: Whenever code changes affect bundle sizes, mount times, or capabilities, the corresponding entry in this ledger must be updated alongside the commit.
2. **Sabotage verification**: During milestone reviews, the auditor verifies that sabotaging a claimed capability immediately causes its mapped verification command to fail.
3. **Zero marketing fluff**: All statements must be direct, factual, and strictly in sentence case.
