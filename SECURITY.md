# Security policy

## Supported versions

| Package | Supported versions |
| :--- | :--- |
| `@lit-core/*` | `>= 0.1.0` |

## Reporting a vulnerability

If you discover a security vulnerability in `@lit-core`, please do not report it through public issue trackers. Instead, report it privately via [GitHub security advisories](https://github.com/lit-core/core/security/advisories/new).

Please include:
- A description of the issue and potential impact
- Steps to reproduce or proof-of-concept code
- The package name and version affected

We aim to acknowledge reports within 48 hours and provide regular status updates until a resolution is released.
